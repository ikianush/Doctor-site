# 🩺 نوبان — سامانه‌ی تحت وب مدیریت نوبت‌دهی مراکز درمانی (نسخه‌ی React)

سامانه‌ای کامل برای جست‌وجوی پزشک، رزرو/لغو/جابه‌جایی آنلاین نوبت، مدیریت برنامه‌ی کاری پزشکان و مدیریت کل سامانه — با **جلوگیری از تداخل نوبت‌ها، صف انتظار هوشمند، یادآوری خودکار، اولویت‌بندی بیماران و پیشنهاد زمان مناسب**.

---

## 🚀 اجرای پروژه

**پیش‌نیاز:** فقط [Node.js](https://nodejs.org) نسخه‌ی ۱۸ یا بالاتر.

فرانت‌اند با **React** نوشته شده و نسخه‌ی ساخته‌شده‌ی آن (`public/assets/js/app.js`) همراه پروژه است؛ پس برای **اجرا** نیازی به `npm install` نیست.

```bash
cd "Final Project"
npm start
```

سپس در مرورگر باز کنید: **http://localhost:3000**

- در macOS می‌توانید روی فایل `start-mac.command` دوبار کلیک کنید (بار اول: راست‌کلیک ← Open).
- در ویندوز روی `start-windows.bat` دوبار کلیک کنید.
- برای ساخت دوباره‌ی داده‌های نمایشی: `npm run reset` (یا از پنل مدیر ← تنظیمات ← بازسازی داده‌ها)
- اجرای آزمون‌های خودکار: `npm test`

### توسعه‌ی فرانت‌اند (React)

اگر کد React داخل `client/src` را تغییر دادید، یک‌بار پکیج‌ها را نصب و سپس باندل را دوباره بسازید:

```bash
npm install        # نصب react ،react-dom و esbuild (فقط یک‌بار)
npm run build      # ساخت public/assets/js/app.js
npm run dev        # حالت توسعه: با هر ذخیره، باندل خودکار بازسازی می‌شود (هم‌زمان npm start را در ترمینال دیگر اجرا کنید)
```
- تغییر پورت: `PORT=4000 npm start`

## ✨ امکانات

### صفحات عمومی
- صفحه‌ی اصلی حرفه‌ای با جست‌وجوی سریع، تخصص‌ها، پزشکان برتر، راهنما، سؤالات متداول
- جست‌وجوی پیشرفته: نام، تخصص، شهر، مرکز، بیمه، جنسیت، «نوبت خالی امروز/این هفته»، حداقل امتیاز + مرتب‌سازی (زودترین نوبت، امتیاز، سابقه، هزینه)
- پروفایل پزشک: بیوگرافی، برنامه‌ی هفتگی، محل‌ها، نمودار امتیازها و نظرات
- **تقویم شمسی رنگی** بر اساس میزان شلوغی هر روز (خلوت/متوسط/شلوغ/تکمیل)
- پیگیری نوبت با کد رهگیری + موقعیت زنده در صف
- **نمایشگر تلویزیونی سالن انتظار** با اعلان صوتی هنگام فراخوانی (`/#/display/1`)
- ورود با رمز عبور یا **رمز یکبارمصرف (OTP)**، ثبت‌نام با اعتبارسنجی کد ملی

### پنل بیمار
- داشبورد با شمارش معکوس تا نوبت بعدی
- رزرو، لغو (با مهلت قابل تنظیم) و **جابه‌جایی نوبت**
- **پذیرش آنلاین «رسیدم»** و مشاهده‌ی جایگاه در صف و زمان انتظار تخمینی
- صف انتظار با نمایش جایگاه
- رسید قابل چاپ با بارکد + **افزودن نوبت به تقویم گوشی (ICS)**
- پرونده‌ی سلامت: تشخیص‌ها، نسخه‌ها، توصیه‌ها و تاریخ مراجعه‌ی بعدی
- ثبت امتیاز و نظر، اعلان‌ها، تیکت پشتیبانی، پروفایل پزشکی (گروه خونی، حساسیت‌ها)

### پنل پزشک
- داشبورد تحلیلی (نمودار ۲۱ روزه، اشغال ظرفیت، نرخ عدم مراجعه، میانگین زمان ویزیت)
- **صف زنده‌ی امروز**: پذیرش، فراخوانی بیمار بعدی بر اساس اولویت، تغییر اولویت
- ثبت پرونده‌ی ویزیت (تشخیص، نسخه، توصیه، مراجعه‌ی بعدی)
- مدیریت برنامه‌ی کاری: شیفت‌ها در چند مرکز، مدت و ظرفیت هر نوبت
- ثبت مرخصی با لغو خودکار نوبت‌ها و پیشنهاد زمان جایگزین به بیماران
- ثبت نوبت حضوری/تلفنی، فهرست بیماران و سوابق، پاسخ به نظرات

### پنل مدیر
- داشبورد جامع: روند نوبت‌ها، وضعیت‌ها، سهم تخصص‌ها و مراکز، ساعات اوج، پزشکان برتر
- مدیریت کامل (CRUD) کاربران، پزشکان، تخصص‌ها و مراکز درمانی
- مدیریت همه‌ی نوبت‌ها با فیلتر و صفحه‌بندی + **خروجی CSV برای اکسل**
- پایش صف‌های انتظار، مدیریت نظرات، پاسخ به تیکت‌ها
- لاگ پیامک‌ها (شبیه‌ساز درگاه پیامک) و **گزارش فعالیت‌ها (Audit Log)**
- تنظیمات: بازه‌ی رزرو، مهلت لغو، زمان یادآوری‌ها، سقف نوبت فعال، رزرو خودکار از صف، حالت تعمیر

## 🧠 قابلیت‌های چالشی (موتور نوبت‌دهی — `server/scheduling.js`)

| قابلیت | پیاده‌سازی |
|---|---|
| **جلوگیری از تداخل** | کنترل ظرفیت هر اسلات؛ منع دو نوبت نزد یک پزشک در یک روز؛ منع نوبت‌های هم‌پوشان یک بیمار نزد پزشکان مختلف؛ منع شیفت‌های متداخل پزشک در مراکز مختلف؛ بررسی مرخصی، زمان گذشته و بازه‌ی مجاز. چون Node تک‌نخی است، بررسی و ثبت به‌صورت اتمیک انجام می‌شود (بدون race condition). |
| **صف انتظار** | عضویت در روزهای تکمیل؛ با لغو، جابه‌جایی یا افزودن شیفت، صف به ترتیب «امتیاز اولویت» و «زمان ثبت» پردازش شده و نفر اولِ بدون تداخل **به‌صورت خودکار** رزرو می‌شود. |
| **یادآوری نوبت** | زمان‌بند هر ۳۰ ثانیه: یادآوری مرحله‌ی اول (۲۴ ساعت قبل) و دوم (۲ ساعت قبل) از طریق اعلان و پیامک؛ تغییر خودکار وضعیت به «عدم مراجعه». |
| **اولویت‌بندی بیماران** | اورژانسی (۱۰۰)، معلولیت (۶۰)، بارداری (۵۰)، سالمند (۴۰)، کودک (۳۰)؛ سالمندی/کودکی خودکار از سال تولد تشخیص داده می‌شود؛ ترتیب فراخوانی در صف زنده و صف انتظار. |
| **پیشنهاد زمان مناسب** | امتیازدهی اسلات‌های آزاد بر اساس فاصله از روز/ساعت دلخواه و میزان شلوغی روز + معرفی پزشکان هم‌تخصص با زودترین نوبت. |

## 🏗 معماری و ساختار

```
Final Project/
├── server/
│   ├── server.js        ← سرور HTTP، روتر و ۷۸ endpoint (REST API)
│   ├── scheduling.js    ← موتور نوبت‌دهی (تداخل، صف انتظار، اولویت، پیشنهاد، یادآوری)
│   ├── db.js            ← پایگاه‌داده‌ی JSON با نوشتن اتمیک
│   ├── seed.js          ← تولید داده‌ی نمایشی واقع‌گرایانه
│   └── util.js          ← تاریخ، رمزنگاری (scrypt)، اعتبارسنجی کد ملی
├── client/src/              ← کد منبع React
│   ├── main.jsx             ← نقطه‌ی ورود (createRoot)
│   ├── App.jsx              ← جدول مسیرها، کنترل دسترسی نقش‌محور، ErrorBoundary
│   ├── lib/                 ← Context سراسری، هوک‌ها، روتر hash، API، تقویم شمسی
│   ├── components/          ← UI پایه، مودال/توست، نمودارهای SVG، ویجت رزرو، رسید
│   ├── layouts/             ← قالب عمومی و قالب پنل (منوی کناری)
│   └── pages/               ← public / patient / doctor / admin
├── build.mjs                ← ساخت باندل با esbuild
├── public/
│   ├── index.html
│   └── assets/
│       ├── css/app.css          ← سیستم طراحی RTL با حالت روشن/تیره
│       ├── fonts/               ← فونت وزیرمتن (آفلاین)
│       └── js/app.js            ← باندل ساخته‌شده‌ی React (خروجی npm run build)
├── tests/run.js         ← آزمون خودکار قوانین نوبت‌دهی
└── data/db.json         ← (هنگام اولین اجرا ساخته می‌شود)
```

- **فرانت‌اند:** SPA با **React 19** (کامپوننت‌های تابعی و Hooks)؛ وضعیت سراسری با Context؛ هوک‌های اختصاصی `useAsync`، `useInterval`، `useBusy`؛ مسیریاب hash اختصاصی با کنترل دسترسی نقش‌محور؛ مودال‌ها با Portal؛ طراحی واکنش‌گرا و راست‌به‌چپ؛ تقویم شمسی و نمودارهای SVG اختصاصی (بدون کتابخانه‌ی جانبی). باندل با **esbuild**.
- **بک‌اند:** Node.js خالص، بدون هیچ وابستگی خارجی؛ احراز هویت توکنی؛ کنترل دسترسی نقش‌محور (بیمار/پزشک/مدیر)؛ قفل موقت پس از ۵ تلاش ناموفق ورود.
- **کاملاً آفلاین:** همه‌ی فایل‌ها (حتی فونت و React) محلی هستند و برای اجرا به اینترنت نیازی ندارد.
